# MyCo-KB v0.8.1

**数据目录默认收敛（向后兼容）** —— 把 0.8.0 的 CLI cwd-relative 默认改回「普通环境 `~/.myco`，仅 DSH agent 环境用工作区相对」，让所有用户零配置即可用，同时保留「会话内 `myco` 绕开文件沙箱」的能力。

> 版本：0.8.1（patch）。功能与 0.8.0 一致，仅调整默认 dataDir 策略。

## 变更内容

### 1. 数据目录默认策略（`lib/core/datadir.js`）
优先级：显式 `dataDir` > 环境变量 `MYCO_DATA` > 默认。

默认值：
- **普通环境**：回退 `~/.myco`（与 0.7.x 一致，无需任何配置）——修复 0.8.0「`myco init` 在一处、`myco status` 在另一处会看到不同（空）数据」的边角行为；
- **DSH agent 会话环境**（检测到 `DSH_SHELL`）：改用 `join(cwd, '.myco')`（工作区相对）——agent 在会话工作区内运行 `myco ...` 时数据落进工作区，绕开 DSH 文件沙箱对工作区外写入的拦截（此前 `~/.myco` 在工作区外会报 `EPERM`）。

### 2. 单测补充
- 新增 `test/datadir.test.js`：显式 `dataDir` > `MYCO_DATA` > DSH_SHELL 工作区相对 > `~/.myco`。

## 升级指引

**路径 A：自包含安装器 / 自动更新**

```bash
bash myco-install-0.8.1.sh        # 新装
myco upgrade                        # 已装自动更新（查 GitHub Releases 最新版）
bash myco-install-0.8.1.sh rollback  # 回滚
```

**路径 B：DSH 插件管理在线更新（git 依赖）**

```bash
bash scripts/install-release.sh git v0.8.1
```

重启 DeepSeek Harness 后生效。

> **说明**：普通用户无需设置任何环境变量/配置；仅在「想让宿主 DSH 插件与 agent 内 CLI 指向同一工作区目录」时，才需在启动前 `export MYCO_DATA=<workspace>/.myco`。
