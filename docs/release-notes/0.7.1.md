# MyCo-KB v0.7.1

**公开内容脱敏** —— 清理公开仓库/官网/制品中的内部与敏感信息，功能与 0.7.0 一致。

> 版本：0.7.1（patch）。0.7.0 把若干内部命名、内网地址与一个 PostHog 摄入 key 随仓库与制品公开，本版将这些全部脱敏。

## 变更内容

### 1. 移除内置 PostHog apiKey
- `cordis.patch.yml` 不再提交默认 `apiKey`；改用环境变量 `POSTHOG_API_KEY` 注入，或本地 profile 覆盖；
- 遥测仍为**默认关（opt-in）**、且需配置 `url` 才发送，行为不变。

### 2. 脱敏内部命名与内网地址
- 公司/项目内部命名 `超合体数据工厂` / `chaoheti` 与真实文档路径 → 占位 `company-kb` / `acme`；
- `docs/cloud-production.md` 内网 GitLab IP / SSH 地址 → `gitlab.example.com` 占位。

### 3. 代码停用词去公司专属词
- `lib/core/myco.js` / `lib/core/taskctx.js` 不再内置 `chaoheti` 停用词。

### 4. 文案与品牌措辞
- 「真菌之库 · 我的公司」改中性表述；
- 个人站点链接改为产品仓库；
- `README.md` 开发机安装节去掉本机日期/备份等内部细节。

> 说明：`我的公司`、`github.com/xiaohaoxing/...` 这类**产品归属信息**（源码/文档/升级仓库链接）予以保留——公开产品需要指向自己的公开仓库；本条不涉及功能变化。

## 升级指引

**路径 A：自包含安装器 / 自动更新**

```bash
bash myco-install-0.7.1.sh        # 新装
myco upgrade                        # 已装自动更新（查 GitHub Releases 最新版）
bash myco-install-0.7.1.sh rollback  # 回滚
```

**路径 B：DSH 插件管理在线更新（git 依赖）**

```bash
bash scripts/install-release.sh git v0.7.1
```

重启 DeepSeek Harness 后生效。
