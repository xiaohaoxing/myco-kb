# MyCo-KB v0.7.0

**按任务动态装配（v0.4）** —— 让 agent 拿到「刚好够用」的知识包子集与工具组合。

> 版本对齐：0.7.0 在 0.6.0（聚合遥测 + 自动更新）作为对齐功能里程碑 v0.4「按任务动态装配」的版本。它补上「**任务 → 知识包子集 → 工具面裁剪**」这段缺失链条，把知识装配从「人声明 profile」演进到「任务驱动自动装配」。

## 核心更新

### 1. 数据面：`myco assemble <目标>`

- 按任务目标**动态装配**知识包子集 + 工具掩码，返回「刚好够用」的知识组合与推荐文档；
- **两层匹配**：
  1. **profile 精确匹配**——任务者的用户 / 环境 / 目标与各 profile 的 `match.{用户,环境,目标}` 逐维命中，命中即锁定该 profile 的 include/exclude；
  2. **知识包子集软匹配**——在 profile 包内再按 `whenToUse` 语义 ×5 > tag ×3 > 文件名 ×2 > 全文 ×1 打分排序，取「刚好够用」的子集；命中为空时回退默认（全量包不裁剪）；
- 产出**可复现 `lockfile`**（写入 `~/.myco/assemble.lock.json`）与 `toolMask`（保留检索/装配基础工具、列出被裁包）；
- 命令：`myco assemble "配置 API 网关生产步骤"`、`myco assemble-status`；HTTP：`/myco/api/assemble?goal=`、`/myco/api/assemble/last`。

### 2. 工具面：`myco_assemble` + agent 作用域装配

- 新增 agent 工具 **`myco_assemble`**（收 goal 返回装配子集 + 推荐文档 + 工具掩码）；
- `applyAgentTools` 提供 agent 作用域装配器：注入**限定到装配子集的 scoped 检索**（`myco_scoped_find`），可显式传 `restrict:{allow,deny}` 施加 agent 作用域裁剪；
- `registerAgentAssembly`（**opt-in**：`cordis.patch.yml` 设 `assemble.auto:true`）订阅 `agent/created`，在 agent 作用域内自动注入 scoped 检索；
- `find(query,{packageIds})` / `findScoped(query,packageIds)` 支持知识包子集限定检索。

### 3. 控制台：「按任务动态装配」区

- 设置页新增「按任务动态装配」区：输入任务目标 → 展示命中包子集 / 推荐文档 / 工具掩码，可回显上次装配的 lockfile。

### 4. 文档与产品化

- 路线图把 v0.4 标记为 DONE；官网/README/CHANGELOG 版本对齐到 0.7.0；
- `docs/v0.4-dynamic-assembly.md`（实现方案）、`site/docs/profiles.md`（按任务动态装配一节）、`site/docs/cli.md`（`myco assemble` 命令）、企业交付 Cookbook 同步更新。

> 边界（如实说明）：装配只影响 agent「**看到哪些**」，**不是权限边界**；
> **已知（待实机核验）**：DSH agent 作用域 `ctx.tools.restrict/register/presentAs/guard` 的真实签名与行为需在真实 DSH agent 运行时确认；`agent/created` 时任务目标往往尚未就绪，自动「目标→装配→掩码」需真实 agent 循环核验。

## 升级指引

**路径 A：自包含安装器 / 自动更新**

```bash
# 新装：下载安装器
bash myco-install-0.7.0.sh
# 已装：自动更新（查 GitHub Releases 最新版）
myco upgrade            # --yes 跳过确认
# 回滚
bash myco-install-0.7.0.sh rollback
```

**路径 B：DSH 插件管理在线更新（git 依赖）**

```bash
bash scripts/install-release.sh git v0.7.0
# 重启 DSH 后，插件管理页出现「更新」按钮 → 点一下即在线更新
```

两种路径均要求标准 DSH bundle（已满足）+ `v*` tag；重启 DeepSeek Harness 后生效（服务端代码启动时加载，控制台刷新见新 UI）。
