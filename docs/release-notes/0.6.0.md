# MyCo-KB v0.6.0

**聚合遥测 + 自动更新** —— 首个带完整更新链路与合规遥测的产品化版本。

> 版本对齐：0.6.0 在 0.5.0（知识更新流全量 + 产品化交付基线）之上，追加两条核心能力：**严格匿名的 opt-in 聚合遥测** 与 **`myco upgrade` 自动更新**。

## 核心更新

### 1. 聚合遥测（telemetry）—— 匿名 · opt-in · 合规

- daemon 定时上报**严格匿名聚合统计**：版本 / 平台 / 知识包数 / 文档数 / tag 数 / 挂载与订阅数 / 运行状态；
- **不含任何知识内容、包 id/名称、文件名、tag 名称、IP**；
- **默认关闭（opt-in）**：控制台底部「统计共享」勾选或 `myco telemetry on` 才上报；未启用零回传；
- 双 provider：`generic`（原始聚合 JSON）与 `posthog`（PostHog `/i/v0/e/` 单事件，`api_key` / 匿名 `distinct_id`）；
- 护栏：需配置 `telemetry.url`（`cordis.patch.yml`）才真正发送，未配置勾选也不上报；`MYCO_TELEMETRY=0` 整机禁用；
- 控制：CLI `myco telemetry status|set <url>|on|off|now`；API `/myco/api/telemetry`；设置页「立即上报」按钮；
- 配套：官网新增公开「隐私与遥测」页（`docs/telemetry.md`）。

### 2. 自动更新 `myco upgrade`

- 查询 GitHub Releases 最新版 → 下载 `myco-install-<version>.sh` → **sha256 校验**（防篡改）→ 版本化安装（旧版本保留可回滚）→ 提示重启生效；
- 命令行：`myco upgrade [--yes]`（`--yes` 跳过确认）；
- 配套自包含安装器：`myco-install-0.6.0.sh`，企业/离线机器可直接 `bash myco-install-0.6.0.sh`。

### 3. 产品化交付（同期落地）

- **repo 包绑定远程 + 同步**：工作区 / 本机知识库 → git 远程；
- **官网 GitHub Pages 自动发布**：`.github/workflows/pages.yml`，push 到 main 即自动构建部署；
- **DSH 插件管理在线更新**（git 依赖模式）：`scripts/install-release.sh git v0.6.0` 切换后，插件管理页出现「更新」按钮，点一下即在线更新 —— 与 `myco upgrade` 构成两条并存更新路径；
- **企业交付全套**：`scripts/build-release.sh`（语法检查 + 全量测试 + 打包 + 产物校验 + sha256）、`scripts/install-release.sh`（安装 / 升级 / 回滚 / 列出版本）、`docs/installation.md`、`docs/enterprise-delivery-cookbook.md`、`docs/release.md`（Release Runbook）；
- 官网修复：首页 raw HTML 内部链接补 base（修复 GitHub Pages 项目页下快速开始等 404）。

## 升级指引

**路径 A：自包含安装器 / 自动更新**

```bash
# 新装：下载安装器
bash myco-install-0.6.0.sh
# 已装：自动更新（查 GitHub Releases 最新版）
myco upgrade            # --yes 跳过确认
# 回滚
bash myco-install-0.6.0.sh rollback
```

**路径 B：DSH 插件管理在线更新（git 依赖）**

```bash
bash scripts/install-release.sh git v0.6.0
# 重启 DSH 后，插件管理页出现「更新」按钮 → 点一下即在线更新
```

两种路径均要求标准 DSH bundle（已满足）+ `v*` tag；重启 DeepSeek Harness 后生效（服务端代码启动时加载，控制台刷新见新 UI）。

## 合规说明

遥测为**默认关 opt-in**，且需配置上报 `url` 才发送。面向要求「零回传」的企业客户：保持不勾选、`myco telemetry off` 或 `MYCO_TELEMETRY=0` 即可，不影响任何功能。
