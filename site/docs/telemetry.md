# 隐私与遥测

MyCo-KB 默认是**本地优先**的知识库工具，知识文件留在你的设备与仓库里，**默认不回传任何内容**。

## 聚合遥测（可选）

为展示产品运行状态，MyCo-KB 内置一个**默认关闭（opt-in）**的聚合遥测：

- **采集**：仅匿名聚合统计——知识包/文档/tag 数量、挂载与订阅数、版本与平台、索引/同步/错误状态。
- **不采集**：任何知识正文、文档标题、文件名、包 id/名称、tag 名称、契约内容、IP、用户/组织身份。
- **opt-in（默认关）**：默认不上报；在设置页勾选「统计共享」或 `myco telemetry on` 才上报。
- **需上报端点**：只有配置了上报 URL（开发者统计端点）才真正发送；未配置则即使勾选也不上报（`myco telemetry status` 可查）。
- **可关闭**：取消勾选 / `myco telemetry off`，或用 `MYCO_TELEMETRY=0` 整机禁用。
- **频率**：随守护进程定时，默认每 24 小时一次；只发聚合计数，不含任何知识内容。

> `instanceId` 为随机生成的 UUID，仅用于去重计数，不关联任何个人或组织。

## 其它外发

- **Webhook 通知**：仅在你配置了飞书/HTTP webhook（`myco webhook set`）时，对 major 契约变更推送摘要。
- **云端同步**：仅在你注册并订阅了云端 git 仓库时，按你的 git 配置同步。

## 联系

涉及隐私问题请通过项目仓库联系维护者。
