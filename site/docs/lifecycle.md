# 生命周期管理

知识像生物一样有生命周期。MyCo-KB 定义四态演进，并只做**报告**、不做破坏性操作。

## 四态演进

| 状态 | 含义 | 典型内容 |
| --- | --- | --- |
| **收件箱** | 未整理的原始输入 | 剪藏、随手记、会议速记 |
| **证据** | 有来源、可回溯的事实 | 带出处的外部资料、实验记录 |
| **常青** | 稳定可信、被引用的事实源 | 架构决策、产品定义、索引页 |
| **原则** | 决策依据与价值观 | 评审标准、口径、价值观 |

演进方向：收件箱 → 证据 → 常青 → 原则。每升一级，内容经过一轮整理与验证。

## 候选扫描（仅报告）

```bash
myco sweep
```

| 候选类型 | 判定 | 建议动作 |
| --- | --- | --- |
| `archive` | 证据页 > 90 天未更新 | 归档（默认归档不删除） |
| `review` | 常青页无出链且无入链（孤页） | 补链，或归档 |

扫描**只报告候选，不自动执行任何删改** —— 人永远在回路里。

```text
$ myco sweep
暂无生命周期候选
```

## 归档哲学

- 淘汰**默认归档不删除**：知识可以失效，但历史不应蒸发；
- 归档是可逆的，随时可以恢复；
- 一切破坏性动作都需要显式人工确认。
